# Modern Arsenal for Elden Ring 0.3.1

A co-op fix release after the first two-player test of 0.3.0. **Both players must install 0.3.1** (the co-op id changes).

**Disclaimer:** unofficial fan mod, not affiliated with, endorsed by or sponsored by Activision, Infinity Ward,
FromSoftware or Bandai Namco. **No game files are included**: the setup builds the mod's data from your own Steam copies
of Elden Ring and Call of Duty: Modern Warfare 2 (2009). Offline or private Seamless Co-op only; never use it in Elden
Ring's official online mode.

## What 0.3.1 fixes

- **Tactical Nuke in co-op now kills the enemies:** the host's game kills every enemy in range, the joining player's game
  finishes off anything still alive after 1 s. In 0.3.0 both games treated every enemy as the other player's, so the
  nuke killed both players and no enemies.
- **No shooting while dead:** firing (and launchers, the AC-130 / nuke keys, melee and heal) is blocked from your death
  until you are alive again after the respawn, in first and third person.
- **Tracers no longer show through walls:** tracers stop at the first wall and the parts hidden behind walls are not drawn.
- Updating: run this setup over 0.3.0; it shows **Update 0.3.0 -> 0.3.1**, keeps your settings and offers **Roll back**.

## Requirements

- Windows 10 or 11, 64-bit; about 6 GB free during setup (about 0.3 GB stays).
- **Elden Ring** on Steam, eldenring.exe **2.7.2.0** (the current Steam build).
- **Call of Duty: Modern Warfare 2 (2009)** on Steam (the single-player / multiplayer Steam release; the current x64
  build). You must own and install it: the setup reads its files.
- **me3 0.13.0** (the mod loader): the setup carries the official installer and runs it when you click.
- **Microsoft Visual C++ 2015-2022 x64 runtime** (usually present): the bundled MW2 file reader (Unlinker) needs it;
  the setup checks for it and links Microsoft's installer if it is missing. The setup program itself does not.
- For co-op only: **Seamless Co-op 2.0.1**, downloaded by each player from Nexus Mods (separate download, never
  included). Both players install the same release and compare the co-op id the setup shows.
- Start Steam before playing; start the game only with the mod's shortcuts (never `ersc_launcher.exe`).

## Known issues

- The 0.3.1 co-op fixes (nuke kills, dead-fire block, tracer occlusion) have not been played with two players yet.
- **Wall occlusion is off**: in third person and for the other player's gun, the gun model is not hidden behind walls
  (the ER-depth test stays off in this release); your own body still covers it.
- The setup is not code-signed: Windows SmartScreen may warn ("More info" > "Run anyway").
- The first install takes 20-40 minutes (the MW2 dumps and conversion); updates rerun only what changed.
- A different MW2 or Elden Ring build than the release's gives a warning or a hash mismatch; co-op needs identical
  files on both PCs.
